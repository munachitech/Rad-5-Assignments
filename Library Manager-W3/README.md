# In-Memory Library Manager CLI

A simple command-line application for managing a collection of books.

## Features

- Add a book
- List all books
- Find a book
- Update a book
- Delete a book
- Toggle book availability
- View library statistics
- Sort books

# Technologies

- JavaScript
- Node.js
- ES6 Modules

# How to Run

Make sure Node.js is installed.

Run:

```bash
node app.js
