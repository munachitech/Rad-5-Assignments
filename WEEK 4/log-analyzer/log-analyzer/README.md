# Log File Analyzer CLI

A Node.js command-line tool for parsing, analyzing, and reporting information from log files.

## Features

- Count log entries by level
- Find errors
- Find the most common errors
- Analyze errors by hour
- Generate summary reports
- Analyze multiple `.log` files in a directory
- Filter by log level
- Filter by date
- Export reports to JSON
- Watch a log file for new entries
