# Versioned Notes

A simple command-line note-taking application built with Node.js.

## Features

- Add notes
- List saved notes
- Delete notes
- Store notes using a JSON file

## Technologies

- Node.js
- JavaScript
- Git
- GitHub
## Usage

Add a note:

node notes.js add "Buy groceries"

List notes:

node notes.js list

Delete a note:

node notes.js delete 1

Clear all notes:

node notes.js clear
